# ChurnZero – AI-Powered Customer Churn Prediction

This project presents an end-to-end machine learning solution developed for the ChurnZero Banking Analytics Challenge. The objective was to predict customer churn using customer demographics, transaction history, digital engagement, complaint behavior, and financial activity data.

## Key Highlights
- Processed 97 banking-related features
- Built ensemble ML models using LightGBM and blending techniques
- Implemented feature engineering and threshold optimization
- Optimized model using PR-AUC, F1 Score, and business cost analysis

## Model Performance
- PR-AUC: 0.9999+
- F1 Score: 0.997+
- Accuracy: 99.7%

## Repository Contents
- Notebook.ipynb → Complete ML pipeline
- Predictions.csv → Final predictions
- Presentation.pdf/pptx → Executive presentation

## Business Impact
The solution helps banks proactively identify high-risk churn customers and reduce customer attrition using data-driven retention strategies.
